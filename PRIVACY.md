# Конфиденциальность DocForge

DocForge обрабатывает выбранные пользователем файлы **локально**; приложение не предназначено для загрузки документов на сторонние серверы. Конвертированные документы обычно сохраняются рядом с исходниками или в выбранном каталоге.

**Сетевые запросы:** установщик скачивает Python, Pandoc и библиотеки из публичных репозиториев при первичной установке и обновлении. Движок конвертации не требует онлайн-обработки содержимого документов. Никакая самостоятельная телеметрия не реализована в предоставленных исходниках.

**Логи:** в Windows локальные журналы установки и запуска создаются в `%LOCALAPPDATA%\DocForge\logs\`; они могут содержать имена файлов и пути. Не публикуйте журнал целиком без удаления персональных путей.

**Права:** интеграция с Проводником и Nautilus регистрируется для текущего пользователя; Linux-установщик может запросить администраторские права только для системных библиотек через apt. Скрипт удаления не удаляет конвертированные документы в других каталогах.
