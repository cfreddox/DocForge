# Code of Conduct

Мы ожидаем уважительного и профессионального общения. Запрещены преследование, оскорбления, дискриминация, раскрытие чужих личных данных и распространение вредоносного кода. Обсуждайте технические вопросы по существу. Для жалоб используйте приватный канал сопровождения репозитория, если он указан; не публикуйте чувствительную информацию в открытых Issues. Сопровождающие могут ограничивать участие нарушителей.
