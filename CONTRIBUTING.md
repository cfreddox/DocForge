# Contributing / Участие

1. Откройте Issue с воспроизводимыми шагами и версией ОС; не загружайте приватные документы.
2. Сделайте fork и отдельную ветку. Изменяйте код модульно, добавляйте регрессионные тесты.
3. Установите зависимости из `requirements.txt`, выполните `python -m pytest -q`, `python -m compileall -q docforge` и (в Linux) `bash -n *.sh`.
4. Создайте PR, опишите изменения и тесты; UI-изменения сопровождайте скриншотом.

Не добавляйте в GitHub скачанные Python runtime, venv, пользовательские файлы, токены или сторонние бинарники без лицензионной проверки. Не обещайте тестирования Windows/GNOME Wayland, если оно реально не проводилось.
