# Changelog

## 1.11.0 (2026-11-19)
- Installation and upgrade share one entry point on both platforms; backups and rollback for changed application files.
- Windows setup reuses existing Python/venv and checks new code before replacing the installed version.
- Nautilus dropzone is persistent after a conversion, with Linux duplicate-instance lock.
- Word-style editor preserves soft line breaks and removes unwanted paragraph spacing during DOCX save.
- Improved dark-theme contrast; added root installers, publishing documentation, CI templates and curated .gitignore.
- Existing conversion engine, PDF tools and user settings retained.

## 1.10.0
- Graphical installer source, separate zone icon, GNOME top-panel extension removal and publishing templates.
