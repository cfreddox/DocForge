# Решение проблем

### Windows: окно установщика показывает ошибку, но консоль пишет SUCCESS
Проверьте реальный результат через `windows\Check-DocForge.cmd` и наличие `venv313\Scripts\python.exe`. Не удаляйте папку DocForge: повторный запуск обновления использует кеш и установленное окружение.

### Windows: программа установлена, но не запускается
Запустите `windows\Diagnose-DocForge.cmd` из полного архива. Приложите `%LOCALAPPDATA%\DocForge\logs\last-launch.log` к Issue (уберите личные пути/данные при необходимости).

### Windows: python.exe was not found
Установщик сначала проверяет существующее окружение, потом зарегистрированный Python 3.13. При ошибке проверьте `%LOCALAPPDATA%\DocForge-InstallCache\python-setup.log`. Не удаляйте Python и не запускайте очистку системы без диагностики.

### Windows: XLSX → PDF создаёт документ без текста
Проверьте PDF в обычном просмотрщике и попробуйте выделить текст. Встроенный резервный экспорт может сохранить текстовый слой с менее точной вёрсткой; для сложного оформления заведите Issue с обезличенным примером.

### Ubuntu: зона после первого файла закрывается
Переустановите интеграцию из 1.11.0. Старые команды `--dropzone-once` заменены постоянным `--dropzone`. Завершите предыдущий процесс зоны, заново откройте её через контекстное меню. Дублирующие зоны блокируются.

### Ubuntu: зона Drag & Drop не реагирует
Попробуйте запуск из меню «DocForge Zone». GNOME Wayland может ограничивать взаимодействие с нестандартными прозрачными окнами: приложите версию GNOME, способ запуска и лог. Контекстное меню «Выбрать формат» является альтернативой.

### Markdown: нет картинки
Используйте `docforge check-md "документ.md"`, проверьте относительный путь и наличие папки `assets/`. Перемещайте Markdown вместе с вложениями.

### Редактор PDF изменил переносы строк
Сохраните исходный PDF и рабочий DOCX. Сложная PDF-разметка не имеет полноценной структуры абзацев, поэтому часть переносов требует ручной корректировки. Сохранение DOCX 1.11.0 уменьшает дополнительные интервалы и сохраняет мягкие переносы внутри абзацев.
