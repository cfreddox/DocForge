# Security / support policy

If you discover a security issue involving local document paths, malicious PDF handling, filename traversal, script execution, or setup downloads, avoid publishing exploit samples publicly. If this project is hosted on GitHub, use its private security advisory feature to report the issue to the repository maintainer.

DocForge processes untrusted files; keep dependencies patched and do not run downloaded installation scripts from untrusted mirrors. Review and verify downloads of Python, Pandoc, PyMuPDF and native PDF components before distributing signed binaries.

The source package contains no account-specific support address; the maintainer should add support contact details before launching a public release.
