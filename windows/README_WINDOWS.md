# DocForge 1.11.0 — Windows 10/11 x64

## Установка для пользователя

1. Распакуйте **весь архив** в папку, содержащую `docforge`, `assets` и `windows`.
2. Дважды запустите `INSTALL-WINDOWS.cmd` в корне проекта (или `windows\START-HERE.cmd`).
3. В графическом окне нажмите «Установить». При первой установке понадобится интернет.
4. По завершении доступны ярлыки **DocForge** и **DocForge Zone** с отдельными иконками.

Графическая оболочка `Setup-DocForge.ps1` работает через штатный WPF в Windows PowerShell 5.1. Она показывает этапы и журнал, а существующий `install.ps1` выполняет установку Python, Pandoc и необходимых библиотек. LibreOffice не устанавливается. При невозможности открыть GUI `START-HERE.cmd` предлагает консольный установщик.

Логи установки: `%LOCALAPPDATA%\DocForge\logs\installer-stdout.log` и `installer-stderr.log`.
Если главное окно не открылось, запустите `windows\Diagnose-DocForge.cmd` и посмотрите `%LOCALAPPDATA%\DocForge\logs\last-launch.log`.

Для удаления сетевой установки из каталога с исходниками выполните `windows\UNINSTALL.cmd`. Он удаляет DocForge и его команды, но не документы, сохранённые за пределами папки приложения.

## Сборка установочного EXE для публикации

Выполняется **на Windows x64**, требуется доступ к интернету, установленный Python 3.13 и Inno Setup 6/7 на машине сборки. Конечному пользователю они не нужны.

```powershell
powershell -ExecutionPolicy Bypass -File windows\build-release.ps1
```

Результат должен появиться в `dist\installer\DocForge-Setup-1.11.0-win-x64.exe` и включать Python-библиотеки и Pandoc. Перед публикацией обязательно проверить установку и преобразование документов на чистых Windows 10 и Windows 11, удаление, цифровую подпись, лицензии зависимостей и антивирусные предупреждения. В текущей Linux-среде бинарник не собран.

Альтернатива: запустить GitHub Actions workflow `.github/workflows/build-windows.yml` на своём репозитории; он формирует артефакт установщика на Windows runner.

## Совместимость

Изменения PDF сохраняются в новом файле, исходный PDF не изменяется. Восстановление вёрстки при PDF → DOCX и рендеринг офисных файлов не гарантируют пиксельную идентичность с Microsoft Word. Приложение выполняет конвертацию локально; скачивание библиотек при первоначальной установке — отдельная операция.


## Установка и обновление поверх старых версий

Запускайте `INSTALL-WINDOWS.cmd` независимо от того, установлена программа или нет. Существующее работоспособное окружение Python используется повторно, а заменяемый код сохраняется для отката. Не удаляйте `%LOCALAPPDATA%\DocForge` ради обновления.

Если Python 3.13 зарегистрирован в Windows, но фактически отсутствует, используйте `REPAIR-PYTHON-WINDOWS.cmd` только после чтения предупреждения. Диагностика: `DIAGNOSE-WINDOWS.cmd`; журнал: `%LOCALAPPDATA%\DocForge-InstallCache\python-setup.log`.

Исправление установщика 1.11.4 устраняет ложную ошибку, когда успешный тест приложения версии 1.11.0 ошибочно сравнивался со строкой версии 1.10.0.
