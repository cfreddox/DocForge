# DocForge 1.11.0 — Release Notes

Дата: 18 ноября 2026 г.

## Изменения для пользователя

- Отдельная иконка для стеклянной зоны Drag & Drop, доступная в списке приложений Ubuntu и в ярлыках Windows.
- Новый графический процесс установки Windows с прогрессом и диагностическим журналом; консольный режим сохранён.
- Linux: новый графический установочный скрипт, если доступны Zenity и системная графическая авторизация.
- GNOME: удалён прежний значок верхней панели `docforge-quick@local`; контекстное меню файлов и сама зона остаются.
- Добавлена инфраструктура сборки EXE-инсталлятора для Windows 10/11 x64, публикационные материалы и контрольные тесты.
- Существующие конвертеры и PDF-редактор сохранены. Форматы и точность не расширялись в данном выпуске.

## Известные ограничения

- Архив Windows — сетевой установщик, для первой установки нужен интернет.
- EXE-инсталлятор из Inno Setup необходимо собрать и испытать на Windows, до публикации как готового бинарника.
- Qt / Drag & Drop под GNOME Wayland требуется испытать на физическом рабочем столе.
- Качество сложной конвертации офисных документов зависит от шрифтов и возможностей рендерера.
- Нужна юридическая проверка совместимости MIT-исходников со сторонними AGPL/GPL/LGPL компонентами перед распространением связанного бинарного пакета.
